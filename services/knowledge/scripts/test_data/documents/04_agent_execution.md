# AI Agent：目标、记忆与环境反馈

来源：Vault 的《AI Agent》（6_Databases/notes/）。本文整理该笔记的执行循环，不描述当前项目已经实现哪些能力。

## 执行循环

笔记从四个环节理解 AI Agent：

1. 带着目标和记忆，通过环境交互了解当前状态。输入可以是文字，也可以是视觉、听觉等感知信息。
2. 根据目标、经验和当前状态生成执行计划。
3. 执行计划，产生文字、图片或操作等结果，并可能改变外部环境。
4. 根据环境反馈调整记忆和计划，再继续推进目标。

## 为什么要看执行后的状态

计划不是制定一次就永远不变。操作会改变环境，而新的环境状态又会影响下一步决策。目标提供方向，记忆提供经验，当前状态说明眼下发生了什么，反馈则帮助修正后续行动。

这篇笔记介绍的是概念性循环，没有给出具体工具协议、持久化存储方案或训练方法，不能据此推断某个 Agent 已经具备这些工程能力。
